# R&E 2차 중간 발표 초안

HTML + Three.js 기반 17장 발표 자료입니다. 밝은 웹페이지 디자인, 오프라인 실행, 실제 Rep5x 부품의 3D 뷰어를 포함합니다.

## 실행

압축을 푼 뒤 `deck.html`을 Chrome 또는 Edge로 열면 됩니다. 기존 `index.html`도 같은 발표로 연결되며 URL의 슬라이드 번호를 유지합니다. 인터넷·계정 연결·별도 설치가 필요하지 않습니다. ZIP 안에서 바로 실행하지 말고 폴더 전체를 먼저 압축 해제해주세요.

## 조작

| 키 | 동작 |
|---|---|
| ← / →, PageUp / PageDown, Space | 슬라이드 이동 |
| Home / End | 처음 / 마지막 |
| O | 전체 슬라이드 목차 |
| N | 발표자 설명, 필요한 자료, 출처 |
| M | 준비 메모 표시·숨김 |
| P | 발표 모드·초안 모드 |
| F | 전체 화면 |
| 드래그 / 휠 | 3D 회전 / 확대 |

7장에서는 k값의 선택 민감도를 조작할 수 있습니다. 11장에서는 B/C축 운동 원리를 확인할 수 있습니다. 12장에서는 공식 부품 10종을 선택해 실제 단품 형상을 볼 수 있습니다.

## 내용과 자료의 상태

- 장수와 순서는 요청된 17장 구성 그대로입니다.
- 연구팀이 제공한 주요 성과는 코드 설계 완료와 Ender-3 V3 SE 기반 Rep5x 제작·개조입니다.
- 1차 발표는 이전 성과 요약과 참고 STL에 사용했습니다.
- 채팅은 **R&E 2학기 프로젝트의 ‘코드 검토 결과’, ‘역전파 기반 k값 결정’**을 중심으로 참고했습니다. 다른 프로젝트 채팅의 실험 수치는 본문에 넣지 않았습니다.
- 7장의 그래프는 1차 아치형 STL과 저장소의 평가식을 이용한 **기하 선택 민감도 시연**입니다. 수정 k의 최종 성능 또는 실제 출력 품질을 나타내지 않습니다.
- 10장은 GUI 구조 시안입니다. 참고 모델 회전만 동작하고 분석 버튼은 미연결 상태로 표시했습니다.
- 11장의 기계는 축 운동을 설명하는 개념도입니다. 실제 조립 CAD·실측 치수·충돌 판정이 아닙니다.
- 12장의 부품은 공식 3MF에서 추출한 실제 메시입니다. 단품을 중앙에 배치한 뷰이며 실제 조립 방향을 뜻하지 않습니다.
- 14·15장의 사진과 결과표는 팀의 실제 자료를 넣도록 남겼습니다. 빈 칸은 결과가 0이라는 뜻이 아닙니다.
- Rep5x 공식 웹은 출처로만 링크했습니다. 외부 서비스나 새로운 발표 라이브러리를 추가하지 않았습니다.

## 수정 위치

`deck.html`에 17장의 슬라이드가 실제 HTML로 작성되어 있습니다. `<!-- 01 · … -->`부터 `<!-- 17 · … -->`까지의 주석이나 `id="slide-7"` 같은 슬라이드 ID로 수정할 장을 찾으세요. JavaScript 문자열이나 템플릿 리터럴을 수정할 필요가 없습니다.

| 수정할 내용 | 위치 |
|---|---|
| 제목·소제목 | 각 `<section class="slide">`의 `<h1>`·`<h2>`와 `<p class="subtitle">` |
| 본문·사진·표·배치 | 각 슬라이드의 `<div class="content">` |
| 하단 준비 메모 | `<div class="prep-note">` |
| 발표자 설명·자료 요청·출처 | 각 슬라이드의 `<template class="slide-notes">` |
| 부품 이름·설명 | 12장의 `#part-menu` 버튼과 `<template data-part-info="…">` |
| 색·글꼴·여백·전환 효과 | `styles.css` |

제목을 수정하면 하단 이동 버튼과 전체 보기 목차에도 반영됩니다. `data-section`은 하단의 구역 이름입니다. `<template>` 안의 메모와 부품 설명은 해당 기능을 사용할 때 표시됩니다.

현재 슬라이드 순서와 요소의 `id`, `data-visual`, `data-model`, `data-part`는 그래프·3D 뷰어·조작 코드에서 사용합니다. 글자와 디자인을 수정할 때 이 연결 값은 유지하세요. `app.js`는 슬라이드 전환과 입력을, `visuals.js`는 3D 렌더링을 담당합니다.

사진 자리에는 실제 이미지의 `<img>`를 넣고 사진 설명을 유지하면 됩니다. 결과표의 `—`는 확인한 측정값으로 교체해주세요. 원본·재구성·실물은 같은 모델 ID 및 조건으로 연결해야 합니다.

`assets/models.js`는 오프라인 3D 메시와 선택 시연 데이터입니다. 원본 CAD·STL은 `assets/originals/`에, 데이터 준비 과정은 `tools/prepare-assets.py`에 있습니다. 이 스크립트 실행은 발표 열기에 필요하지 않습니다.
