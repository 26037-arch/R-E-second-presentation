04 · CORE ALGORITHMS

핵심 코드 요약

원뿔 슬라이싱으로 출력 명령을 만들고, 퇴적 복원으로 형상 일치도를 평가

G-code 생성

Pypipeline.py + backtransform.py
1warped = transform_cone(fine.vertices, theta, direction)
2items = slice_mesh(warped, layer_height=0.3)
3real, stats = backtransform(items, theta, direction)
4rep, stats = to_rep5x(real, theta, direction, REP5X)
5rep, stats = add_c_rewinds(rep, REP5X)
6gc.write(rep, output_path)
7assert internal_gcode_check(output_path)["valid"]
ΔE는 경로 길이비로 보정 · 저장 후 좌표와 B/C 범위 검사

좌표 변환과 슬라이싱 선택한 원뿔각으로 STL을 변환해
평면 슬라이싱한 뒤, 경로를 원래 좌표계로 되돌리기

5축 명령 생성 경로를 Rep5x의 XYZ/B/C 명령으로 변환하고,
실제 경로 길이에 맞게 압출량 ΔE를 보정

파일 저장과 검사 C축 되감기를 넣어 G-code를 저장하고,
좌표 유효성과 B/C 회전 범위를 검사

VOLCO를 이용한 IoU 계산

Pydeposition_events.py + volco_oriented.py
1# G90/G91, M82/M83, G92를 해석해 ΔE와 자세 복원
2if event.delta_e > 0:
3    volume += pi * (filament_diameter/2)**2 * delta_e
4    needed = round(volume / voxel_size**3) - len(voxels)
5    center = tip + tool_direction(B, C) * 0.2
6    voxels.update(nearest_empty(center, needed))
7IoU = len(target & voxels) / len(target | voxels)
동일 좌표계의 원본 STL과 복원 voxel 비교

압출과 자세 복원 G-code의 ΔE로 퇴적 부피를 계산하고,
XYZ/B/C로 노즐 끝을 이용해 위치, 방향 복원

퇴적 형상 재구성 VOLCO의 구형 퇴적 규칙에 방향을 반영해
가까운 빈 voxel을 채우고 누적 압출 부피를 맞춤

원본 STL과 비교 IoU = 교집합 부피 / 합집합 부피
1에 가까울수록 원본과 복원 형상 일치

자료 메모코드는 핵심 구현을 발췌·축약한 설명용 표현입니다. 전체 함수와 기본 설정은 발표자 메모의 출처에서 확인할 수 있습니다.

05 · LEARNING k

형상 특징에서 k를 예측하고 역전파로 수정

38차원 MLP의 연속값 회귀 출력과 선택 확률을 연결

입력 형상에서 k까지
크기·부피 8개 + 반경 프로필 20개 + 법선 히스토그램 10개
ki = Softplus(MLPw(xi))
Jij = Gij − ki|θj|G = 평면 대비 서포트 감소 (%p)
pij = softmaxj(Jij/T)
L = 1N Σi,j pij(Qimax − Qij)

손실의 기울기가 k와 MLP 가중치를 갱신
새 STL 추론에서는 k를 예측한 뒤 기존 J의 최대 후보를 선택

3 / 3종료 기준 만족
240–540회50개 고정 후 추가 업데이트

100회 동안 선택 후보가 유지되고, 개별 k의 변화폭 < 0.01.
그래프는 모든 50개 형상에 대한 평균이며, 시드별 최종 k는 서로 다릅니다.

자료 메모학습 label: 50개 STL × 46후보의 이상적 적층 형상 IoU. 학습 곡선과 실제 G-code 복원 IoU는 구분

06 · ANGLE VALIDATION

선택한 원뿔각의 복원 형상을 IoU로 확인

전체 G-code 후보 결과가 확보된 mushroom_03을 대표 검증 모델로 사용

층고 0.3 mm · 선폭/인필 간격 0.45 mm · voxel 0.3 mm · 이동 샘플 0.15 mm

학습 k가 선택한 각도
0°
선택각 IoU92.624%
측정 최대 · 10°93.172%

선택값은 측정 최대의 99.41%.
최대값과의 차이는 0.547 %p입니다.

같은 조건으로 3회 반복 확인0° · 10° · 12°의 G-code와 복원 voxel이 모두 동일

이 모델에서 선형 J는 k에 따라 0° 또는 12°를 선택
측정 최대인 10°를 선택하려면 평가식의 추가 항 검토 필요

자료 메모IoU = 교집합 / 합집합. 4개 격자 내부 측정 위치의 부피를 집계한 수치입니다. 실물 스캔이 아닌 G-code 퇴적 복원 비교입니다.
