03 · ANGLE EVALUATION

원뿔각 평가 코드 제작

서포트 감소 이득과 각도 비용을 함께 고려하는 선택

J(θ, d) = ΔS(θ, d) − k|θ|
ΔS
평면 대비 서포트 필요 면적 비율 감소량 (%p)
k
각도 1°에 부여하는 비용 가중치 (%p/°)
θ, d
원뿔각과 방향 outward / inward
gain = baseline - support
cost = k * angle_deg
return gain - cost

기본 k = 0.20 · 코드의 각도 탐색 0~44°, 2° 간격
k는 원뿔 기울기 tanθ와 구분되는 평가 가중치입니다.

평가와 선택의 구조

  • STL의 면 법선과 반경 성분 분석

    국소 원뿔 적층 방향을 기준으로 서포트 필요 면을 판정

  • 후보별 점수 계산

    각도와 방향마다 ΔS 및 k에 따른 비용을 계산

  • 추천값과 선택 이유 반환

    최대 J 후보와 함께 남은 서포트, 이득, 비용을 기록

추천 각도를 G-code 경로와 형상 재구성 단계에서 다시 검증합니다.
자료 메모 팀에서 확정한 평가 코드 버전과 실제 입력·출력 예시를 추가해주세요.
